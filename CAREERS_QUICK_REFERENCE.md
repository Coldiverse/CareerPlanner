## Career Paths Overview

### STEM Career Paths

**Computer Science Path**
```
Boot Camp (3mo) / Bachelor (4yr)
        ↓
  Junior Developer ($60k)
        ↓
  Software Engineer ($85k–$130k)
        ↓
  Senior Engineer ($130k–$180k)
        ↓
  Tech Lead / Architect ($180k–$250k+)
        ↓
  CTO / VP Engineering ($200k+)
```

**Data Science Path**
```
Bachelor (4yr) + Master (2yr) or Boot Camp (4mo)
        ↓
  Data Analyst ($60k)
        ↓
  Data Scientist ($95k–$145k)
        ↓
  Senior Data Scientist ($145k–$220k)
        ↓
  Analytics Director ($250k+)
```

**Engineering Path**
```
Bachelor (4yr) + PE License (2-4yr)
        ↓
  Junior Engineer ($70k)
        ↓
  Engineer ($110k)
        ↓
  Senior Engineer ($160k)
        ↓
  Principal Engineer / Manager ($200k+)
```

### How Weights Work
- **0.90–0.95**: Core requirement (specialist focus)
- **0.70–0.85**: Important requirement (strong foundation)
- **0.50–0.65**: Moderate requirement (meaningful contribution)
- **0.35–0.45**: Tertiary requirement (useful but not essential)
